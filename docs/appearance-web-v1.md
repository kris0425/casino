# 網站版個人造型 v1

玩家使用 `/玩家 造型` 取得 15 分鐘有效的簽章網址。網址綁定 Discord 使用者、伺服器與發起頻道；前端傳入的價格、商品擁有權及穿戴資料都會由機器人後端重新驗證。

## 第一版內容

- 6 個部位：背景、服裝、頭飾、臉部、手持物、光環／邊框。
- 4 個主題：賭場之王、交通大亨、暗夜劫案、萌犬航空。
- 24 件商品；賭場之王六件套為免費基本造型，其餘商品合計可回收 134,000,000 金幣。
- 即時試穿、購買、穿戴、卸下、復原與 3 組命名預設。
- Discord 造型名片發布，單一玩家冷卻 30 秒。
- 純外觀系統，不提供收益、勝率或搶劫能力加成。

## 資料表

- `player_cosmetics`：玩家已購買造型。
- `player_appearance`：六部位目前穿戴狀態。
- `appearance_presets`：每位玩家最多 3 組造型 JSON 預設。

四張主題背景由 OpenAI ImageGen 製作，其他部位採網站原生可縮放圖層，讓手機即時試穿不需等待伺服器重新產圖。

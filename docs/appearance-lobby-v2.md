# 人物展示大廳 v2

造型網站首頁改為遊戲式人物展示大廳。畫面中央顯示目前試穿人物，左右各顯示前後候選角色；玩家可直接點選已擁有人物，或購買尚未解鎖的人物。

## 角色

- 黑金首席荷官：免費基本人物。
- 銀翼運輸指揮官：20,000,000 金幣。
- 紫影情報專員：30,000,000 金幣。
- 粉雲萌犬機長：40,000,000 金幣。

四名人物皆為成年原創角色，由 OpenAI ImageGen 依使用者提供的角色選擇畫面作為構圖與呈現方式參考，再以 chroma-key 去背為透明 PNG；未複製參考圖人物、服裝、武器或 UI。

## 相容性

- `character` 加入既有 `player_appearance` 通用部位資料，不需要新增資料表。
- 舊玩家尚未有 `character` 紀錄時，自動使用免費人物。
- 舊版預設讀取時會與新版預設值合併，因此不會出現無人物狀態。
- Discord 造型名片以主題背景作主圖，人物透明素材作縮圖。

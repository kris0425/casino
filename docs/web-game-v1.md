# 網頁遊戲第一階段

## 架構

```text
Discord /玩家 遊戲
        │  30 分鐘 HMAC 簽章工作階段
        ▼
activity/public/game.* ── /api/game ── src/index.js 遊戲服務 ── casino.sqlite
        │
        ├─ 人物造型工作室
        └─ 網頁麻將
```

瀏覽器只負責畫面與操作。金庫、負債、體力、資產、成就及交通公司資料皆由 Oracle 上的遊戲服務讀取；每日體力恢復也由伺服器交易驗證。

## 已拆分資料

- `src/game-data/cosmetics.js`：人物、背景、服裝、配件商品與預設造型。
- `src/game-data/web-game.js`：網頁遊戲版本、模組導覽、交通類型與資產摘要函式。

既有資料庫表、造型商品 ID 與玩家持有紀錄沒有變更。

## 第一版範圍

- 玩家即時金庫、負債、體力、稱號與造型展示。
- 資產收藏與高價值資產摘要。
- 全部成就進度。
- 航空、鐵路、客運及貨運公司狀態。
- 每日免費體力恢復。
- 造型工作室與網頁麻將入口。

交通事業操作、資產交易及賭場遊戲仍使用 Discord；後續階段再逐項搬入網站，避免一次重寫破壞既有經濟資料。
